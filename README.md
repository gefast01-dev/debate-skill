# Debate Skill

Последовательное обсуждение задачи разными ИИ с обязательным интервью и общей историей в Markdown. Пользователь сам выбирает и запускает модели, а также решает, когда подводить итоги.

Sequential AI debate through shared Markdown files, with a mandatory clarification interview and a human-controlled final decision. Instructions are in Russian. The Python helper uses only the standard library and makes no model or network calls.

## Установка по ссылке

Передайте агенту:

```text
Установи скилл из https://github.com/gefast01-dev/debate-skill
Прочитай INSTALL.md и выполни установку для своей среды.
Сохрани правила процесса, формат файлов и Python-скрипт.
Если подключаешься к существующим обсуждениям, используй их общую папку.
```

[Инструкция установки и адаптации для агента](INSTALL.md).

В Codex можно использовать:

```text
$skill-installer install https://github.com/gefast01-dev/debate-skill/tree/main/skills/debate
```

Установка по ссылке требует среды с доступом к сети, локальным файлам и Python 3.10+. Совместимость с другими агентами зависит от их способа подключения инструкций; прогоны в Gemini и Claude пока не выполнены. В веб-чате без файловых инструментов сохранение и передачу файлов выполняет пользователь.

## Использование

```text
$debate новая задача: <постановка>
$debate B продолжай
$debate A продолжай
$debate продолжай
$debate задача "Название" B продолжай
$debate список
$debate статус
$debate итоги
```

A/B — подписи участников. Фактическую модель пользователь переключает в своем приложении.

1. Первая модель сохраняет исходную задачу, интервьюирует пользователя и предъявляет уточненную постановку. Решения до подтверждения не предлагаются.
2. После подтверждения каждый запуск добавляет один ход: предложение, конструктивную критику, проверки или вопрос пользователю.
3. Разногласия получают постоянные номера и статусы. Для ключевых позиций указываются условия пересмотра мнения. При тупике или неизвестных предпочтениях модель спрашивает пользователя.
4. Модель рекомендует продолжить, получить ответ пользователя или подвести итоги. Третий файл создается только по команде пользователя; нерешенные вопросы не скрываются.

## Где хранятся обсуждения

По умолчанию `~/Debates` (папка `Debates` внутри домашней папки пользователя). При установке можно задать другую общую абсолютную папку в `skills/debate/settings.json`. Приоритет настроек: `--root` → `DEBATE_HOME` → `settings.json`; `~` раскрывается в домашнюю папку.

Каждая задача имеет отдельную подпапку:

- `01_task.md` — исходный текст, интервью и подтвержденная постановка.
- `02_discussion.md` — журнал ходов и ответов пользователя; появляется после подтверждения.
- `03_result.md` — самостоятельный итог; появляется по команде пользователя.

`index.json` хранит поиск задач и привязки к сеансам. Несколько агентов должны использовать одну папку данных и работать по очереди. Копия скилла сама по себе не передает историю обсуждений между компьютерами.

## Состав

- [skills/debate/SKILL.md](skills/debate/SKILL.md) — краткая основная инструкция.
- `skills/debate/references/` — инструкции интервью, обсуждения и итогов; читаются по необходимости.
- `skills/debate/scripts/debate_state.py` — создание задач, реестр и поиск.
- `tests/test_debate_state.py` — изолированные проверки помощника.

```text
python -X utf8 -m unittest discover -s tests -v
```

Помощник обеспечивает операции с реестром, но не проверяет смысл аргументов и не гарантирует соблюдение протокола моделью. Статус в реестре не заменяет подтверждения пользователя.

## Источники идей

Правила учета разногласий, проверки оснований согласия и условий пересмотра позиции развивались с учетом подходов [agent-debate](https://github.com/gumbel-ai/agent-debate) и [multi-agent-debate](https://github.com/maxim-saplin/multi-agent-debate). Этот проект сохраняет ручную передачу хода, обязательное интервью и три файла обсуждения.
